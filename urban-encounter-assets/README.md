# 都市邂逅素材

77 位角色、340 套服装、44 张场景背景。当前催眠状态图 340 / 340，按用户确认的半垂睁眼、紫色渐变失焦眼神逐张制作。

`index.html` 可对照每套服装的常态与催眠状态。`manifest.json` 提供稳定角色编号、别名、服装、场景分类与图片直链。原始 PNG 保留本地，图床 WebP 保持原尺寸和透明通道。

`appearance-resolver.mjs` 只读取状态并选择图片：明确服装优先于地点；卧室睡前使用居家装，街道通勤使用日常装，公园购物使用休闲装，对应职业地点使用本人职业装。当前催眠选择同一套服装的催眠图，效果到期或解除恢复同套常态图。永久信念变化与好感、服从数值不会单独触发催眠外观。该模块不写入游戏变量。
